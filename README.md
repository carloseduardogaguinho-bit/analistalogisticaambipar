# Sistema de Gestão Logística - Ambipar

Sistema de apoio operacional e tático para **Analista de Logística** na **Ambipar**.

## 📌 Visão Geral do Projeto
Este sistema é desenvolvido para centralizar, automatizar e otimizar as rotinas diárias da operação logística:
- Gestão e rastreamento de frotas e cargas (resíduos perigosos, cargas industriais e atendimento a emergências)
- Controle e validação de documentação ambiental e fiscal (MTR - Manifesto de Transporte de Resíduos, CDF, CTe, DACTE, FISPQ)
- Otimização de rotas, tempos de ciclo (lead time, SLA) e monitoramento de janelas de coleta/descarte
- Indicadores de performance (KPIs): OTIF, custo por km/tonelada, emissão de carbono (ESG) e ocupação de veículos
- Alertas de ocorrências operacionais e gestão de não-conformidades

## 🛠️ Tecnologias
- Interface moderna, responsiva e ágil
- Automação de planilhas e relatórios operacionais
- Integração contínua com Git / GitHub
